Open Ru Search — это не поисковая система и не хранилище поисковых баз. Это лёгкая надстройка над 21 поисковиком, Википедией и популярными AI-сервисами, которая помогает отправить запрос в нужную систему, не переключаясь вручную между вкладками. Весь браузер умещается в один index.html и работает без установки, сборки и внешних зависимостей.

Возможности
Два режима поиска — обычный поиск и Википоиск с выводом статей прямо на странице

20 поисковик с фильтром по регионам: Мир, РФ, Европа, Азия

AI-режим — быстрый переход в Google AI (udm=50)

История поиска — до 100 запросов в localStorage, контекстное меню, навигация стрелками

Закреплённые сайты — редактируемый ряд быстрых ссылок

Тёмная и светлая темы с сохранением выбора

Свой фон — загрузка картинки с автоопределением доминирующего цвета заголовка

Палитра — цветовой круг HSV с полем HEX для цвета надписи
